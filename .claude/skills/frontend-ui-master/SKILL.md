# Frontend UI master

1. Model loading, empty, success, validation, error, offline, retry, and permission states explicitly.
2. Prefer semantic HTML and established components; keep state close to its owner and derive rather than duplicate values.
3. Handle async races with cancellation or stale-result guards and clean up listeners, timers, media, and observers.
4. Preserve keyboard behavior, focus restoration, announcements, labels, contrast, zoom, mobile layout, RTL, and reduced motion.
5. Avoid visual-only controls, unstable keys, effect-driven derived state, unnecessary rerenders, and monolithic components.
6. Validate external content and render user input safely.
7. Test behavior through user-observable roles and outcomes rather than implementation details.
8. Verify dynamic imports, route errors, bundle impact, and degraded network behavior.
