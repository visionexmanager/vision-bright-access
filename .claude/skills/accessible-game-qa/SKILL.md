# Accessible game QA

1. Complete the core loop without a mouse: enter, understand instructions, start, play, pause, recover, finish, replay, and exit.
2. Verify semantic controls, stable accessible names, logical focus, visible focus, announcements, and no focus traps.
3. Ensure status changes are announced without flooding the screen reader.
4. Provide non-color cues, scalable text, sufficient contrast, reduced motion, captions/transcripts, and adjustable audio.
5. Ensure touch targets, orientation, zoom, RTL, and virtual-keyboard behavior remain usable.
6. For timing mechanics, offer pause, extension, or a non-timed mode when the timing is not essential.
7. Test success and failure paths with keyboard and representative assistive technology.
8. Report blockers by user impact with exact reproduction steps and a verifiable fix criterion.
