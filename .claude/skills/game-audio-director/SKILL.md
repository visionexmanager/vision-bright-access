# Game audio director

1. Define an audio map for navigation, actions, hazards, rewards, state changes, ambience, music, and narration.
2. Use distinct, short, non-fatiguing cues with consistent meaning; never rely on audio alone unless it is an intentional audio game with alternatives.
3. Respect autoplay restrictions and create/resume audio only from user gestures.
4. Provide independent master, speech, effects, and music controls plus mute and persisted preferences.
5. Handle overlapping cues, ducking, interruption, cleanup, route changes, latency, missing assets, and repeated play.
6. Keep speech localized, pronounceable, cancellable, and synchronized with visible text or transcripts.
7. Test headphones/speakers, screen readers, mute, reduced sensory load, mobile suspension, and audio-only completion.
8. Never clone or publish a voice without appropriate consent and provenance.
