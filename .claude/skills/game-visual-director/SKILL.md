# Game visual director

1. Establish an art brief: player age, mood, palette, lighting, camera, material language, readability, and brand fit.
2. Reuse the established visual system before introducing a new style.
3. Treat assets as production inputs: verify license/provenance, dimensions, format, transparency, compression, naming, and fallback behavior.
4. Preserve subject readability, text contrast, color-independent cues, zoom, high contrast, RTL layout, and reduced visual clutter.
5. Optimize responsive crops and avoid embedding translatable text in images.
6. Use layered feedback for hover/focus, action, success, damage, cooldown, and disabled states.
7. Validate assets at real render sizes and on low-bandwidth/mobile conditions.
8. Keep visual effects synchronized with the authoritative game event and optional for reduced motion.
