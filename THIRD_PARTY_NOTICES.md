# Third-party data notices

## Free-reply phrase lexicon (`supabase/functions/_shared/chatPhraseLexicon.ts`)

Generated by `scripts/lexicon/build-phrase-lexicon.mjs`. The file holds folded
keywords only; neither dataset is copied into this repository.

- **MASSIVE** — © Amazon.com Inc., released under CC BY 4.0.
  <https://github.com/alexa/massive> · FitzGerald et al., "MASSIVE: A 1M-Example
  Multilingual Natural Language Understanding Dataset with 51 Typologically-Diverse
  Languages", 2022. Used for greeting phrases and for words typical of
  everyday-assistant requests.
- **Tatoeba** — sentences contributed by the Tatoeba community, CC BY 2.0 FR.
  <https://tatoeba.org> · exports from <https://downloads.tatoeba.org/exports/>.
  Used only to discard keywords that are too common in ordinary sentences.

To regenerate: download both datasets into a scratch folder (not the repository),
run the script with `--massive` and `--tatoeba`, and review the diff.
