# Accessible games release test plan

Automated checks cover semantic events, keyboard routes, registry integrity, and rejection of unapproved spatial audio. Premium approval additionally requires moderated complete-play sessions with blind and low-vision users.

Manual matrix: NVDA + Firefox/Chrome on Windows, JAWS + Chrome/Edge on Windows, VoiceOver + Safari on macOS/iOS, and TalkBack + Chrome on Android. Verify headings and landmarks, button names, instructions, state changes, score and results, error recovery, focus order, no keyboard trap, touch exploration, speech interruption, audio balance, direction accuracy, and equivalent Blind vs Sighted rules.

No game is approved from automated tests alone.
