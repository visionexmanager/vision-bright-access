# Existing games premium upgrade audit

All 22 games retain their routes, VX economy integration, old local high-score keys, and original gameplay components. The premium adapter now supplies a consistent game page, settings, restart/pause controls, statistics, achievements, visual profiles, accessible status regions, and result/replay surface.

Priority 1 uses featured/trending status as the current popularity proxy because the catalogue has no historical server play totals yet. Priority 2 is assigned to sub-62 quality scores; remaining games are Priority 3.

No game is marked premium-complete while its commissioned audio and dedicated HD visual package are pending. Manual assistive-technology and real-device gameplay passes remain release gates.
