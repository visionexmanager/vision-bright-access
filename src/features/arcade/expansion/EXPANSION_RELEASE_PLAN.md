# Visionex Arcade premium expansion

The requested 34-game expansion is divided into six controlled batches: Classic, Puzzle, Strategy, Educational, Kids, and Reaction & Skill. A game enters the public catalogue only when gameplay, graphics, audio, performance, and accessibility are all approved.

The current release blocker is production audio: the approved audio library contains no playable licensed sources. Publishing silent or placeholder-backed games would violate the Phase 7 acceptance contract. The catalogue, routes, and public registry therefore remain unchanged until a complete first batch passes the gate.

Recommended production order:

1. Accessible classics: Chess, Checkers, 2048, Tic Tac Toe, Connect Four.
2. Accessible puzzles: Sudoku, Word Search, Crossword, Logic Puzzles.
3. Educational and kids batch with professionally recorded narration.
4. Reaction games after mobile latency profiling.
5. Strategy games after AI-opponent and performance budgets are verified.
