# Visionex Kids narration release gate

Letters, numbers, colors, shapes, corrections, instructions, encouragement, and rewards require recorded natural human voices. Synthetic preview speech and unlicensed samples are not release assets.

Each language pack must document speaker consent, commercial usage rights, locale, age-appropriate script review, 48 kHz master, loudness and peak measurements, pronunciation review by a native speaker, and listening tests on phone speakers and headphones.

Initial Arabic scripts include “ممتاز!”, “أحسنت!”, and “حاول مرة أخرى”. Initial English equivalents are “Excellent!”, “Well done!”, and “Try again”. The scripts are production requirements only; no placeholder recordings are bundled.
